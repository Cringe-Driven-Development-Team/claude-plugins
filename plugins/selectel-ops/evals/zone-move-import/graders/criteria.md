Ответ хорош, если одновременно:
1. Переносит зону функцией панели Selectel «Перенести в другой проект» (записи и id сохраняются), а не удалением и созданием заново — удаление даёт простой, а вторую зону с тем же именем в другом проекте через API не создать.
2. Отмечает, что NS Selectel (a/b/c/d.ns.selectel.ru) общие для проектов — делегирование у регистратора менять не нужно.
3. Импорт в Pulumi: опция `import` с id = имя зоны с точкой (`example.org.`), переменная `INFRA_PROJECT_ID=<id проекта B>` на время и `pulumi preview`, и `pulumi up`; `preview` должен показать `import` без create/delete; `up` — после подтверждения человека; затем опцию `import` убрать и убедиться, что `preview` без изменений.
Ответ плох, если предлагает удалить и пересоздать зону, менять NS у регистратора или оставляет `INFRA_PROJECT_ID` только для `up`.
